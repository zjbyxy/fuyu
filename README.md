# 浮屿 FuYu

> 漂浮在 Windows 桌面顶端的智能胶囊 —— 像手机灵动岛一样，但更强。

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-lightgrey.svg)
![Electron](https://img.shields.io/badge/Electron-33-47848F.svg)

浮屿（FuYu）是一个常驻 Windows 桌面顶端的胶囊式智能助手。平时收起为一条低调的胶囊，鼠标移过自动展开；内置 DeepSeek AI 对话、全平台音乐控制与同步歌词、系统状态仪表盘、文件暂存区、番茄钟、喝水提醒等功能，界面大小随内容自适应。

## ✨ 功能

- **胶囊常驻 + 悬停展开**：平时一条半透明胶囊悬于屏幕顶部，鼠标靠近自动展开，移开自动收起；全屏工作（游戏/视频/CAD 最大化窗口覆盖）时自动缩成顶部小横条，不挡内容
- **AI 对话（DeepSeek）**：OpenAI 兼容接口，支持任意模型名、流式输出、思维链展示、多会话历史、Markdown/代码渲染
- **音乐控制 + 同步歌词**：基于 Windows 系统媒体控制（SMTC），支持 QQ音乐、网易云音乐、酷狗、Spotify 等所有接入系统媒体控制的播放器；自动匹配歌词（QQ音乐官方曲库优先、网易云兜底），三行歌词窗口逐句高亮；收起态胶囊实时滚动显示当前歌词
- **系统状态仪表盘**：16 核心负载芯柱图、CPU/GPU/内存、显存与 GPU 功耗（NVIDIA）、实时网速与累计流量、TOP 进程列表（真实进程图标，按 CPU/内存排序）、电池与磁盘
- **文件暂存区**：桌面文件/文件夹直接拖进胶囊即可暂存，图标/列表双视图，完整文件信息，可拖出、复制取出、直接打开或定位
- **番茄钟**：赛博朋克霓虹表盘，专注/小憩/长休自动轮换，系统通知
- **便签日历**：月视图日历 + 按日待办，有事项的日期打点
- **剪贴板历史**：最近 50 条，点击即复制
- **天气**：Open-Meteo 免费 API，三天预报，城市可配置
- **喝水提醒**：可设间隔（15~180 分钟），胶囊上有水滴倒计时
- **独立设置窗口**：字体样式/大小、强调色、透明度、贴边距离、开机自启等，实时生效

## 🚀 快速开始

### 环境要求

- Windows 10 / 11
- Node.js 18+（建议 20+）

### 安装与运行

```bash
# 1. 安装依赖（国内网络建议先设置 Electron 镜像）
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm install --registry=https://registry.npmmirror.com

# 2. 启动
npm start

# 3. 打包为单文件便携版（可选）
npm run dist
```

### 首次配置

1. 鼠标悬停胶囊展开 → 点击右上角**齿轮**打开设置窗口
2. 在「DeepSeek API」中填入你的 API Key（模型名可填任意版本）
3. 其余选项（天气城市、喝水提醒、外观等）按需调整，保存即实时生效

## ⌨️ 操作方式

| 操作 | 说明 |
|------|------|
| 鼠标悬停胶囊 | 自动展开 |
| `Ctrl + Alt + I` | 固定展开 / 收起 |
| `Esc` | 收起 |
| 拖文件到胶囊 | 自动展开暂存界面并接收 |
| 托盘右键 | 显示/隐藏、退出 |

## 📁 数据与配置

- 配置文件：`%APPDATA%\浮屿\config.json`（API Key、外观、提醒等）
- 文件暂存记录：`%APPDATA%\浮屿\shelf.json`（只记录路径，不复制文件本体）
